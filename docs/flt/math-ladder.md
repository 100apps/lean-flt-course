# 数学阶梯

高中数学足够开始 Lean，但不够直接理解 Wiles 证明。我们会沿证明需要逐级补数学，而不是先读完一整套大学教材。

## 第一级：高中知识的形式化

- 自然数、整数；
- 幂、奇偶性；
- 整除、最大公因数；
- 素数；
- 同余。

对应仓库：`FreyPackage` 的 `p`、`hp5`、`pp`、`hgcdab`、`ha4`、`hb2`。

## 第二级：代数语言

- 群：带有可逆运算的对称结构；
- 环：可加减乘的结构；
- 域：非零元素还可以相除；
- 向量空间和模；
- 线性映射与矩阵。

对应仓库：椭圆曲线上的点、有限域、二维 Galois 表示。

## 第三级：数论与椭圆曲线

- 有限域 `ZMod p`；
- 多项式和代数扩张；
- 椭圆曲线群；
- `p`-扭点；
- 好约化、坏约化、半稳定性。

对应仓库：`FreyPackage.freyCurve`、`GaloisRepIsIrreducible`。

## 第四级：模形式与 Galois 表示

- 复上半平面；
- 模群作用；
- 模形式与尖点形式；
- q 展开；
- Hecke 算子；
- 从椭圆曲线和模形式得到的 Galois 表示。

对应仓库：`frey_isModular`、`level_lowering_to_two`。

## 第五级：Wiles 深水区

- 局部与整体 Galois 理论；
- 表示的变形；
- 变形环；
- Hecke 代数；
- `R = T`；
- Taylor–Wiles patching；
- Ribet 降层。

这一层需要大学高年级到研究生数学。课程会先建立概念地图，再选择局部、可审核的 Lean 定理深入。

## 每一级的判断标准

“理解”至少包括三件事：

1. 能用自己的话说明对象是什么；
2. 能指出它在证明链中承担的输入和输出；
3. 能读懂至少一个与它有关的小型 Lean 定义或引理。
