# 手机学习方式

手机端主要用于阅读、思考和提交答案；Docker 负责真正运行 Lean。

## 每一课的流程

1. 在 GitHub Pages 阅读课程。
2. 不看答案，先在聊天中写出你认为正确的 Lean 代码。
3. 我把代码放入 Docker 中运行，并把 Lean 的错误信息翻译成人话。
4. 通过后，将答案和学习记录提交到 GitHub。
5. 在[学习进度](../progress.md)中勾选本课。

## 手机上的代码输入

Lean 符号可以先使用 ASCII 写法：

| 符号 | 手机不方便时可写成 |
|---|---|
| `→` | `->` |
| `∀` | `forall` |
| `∧` | `/\\` |
| `∨` | `\\/` |
| `¬` | `not` |
| `≤` | `<=` |
| `≠` | `!=` |

聊天里也可以直接用自然语言回答，例如：“先 `intro hP`，然后 `exact hP`”。我会帮你转换成 Lean。

## 关于在线交互

GitHub Pages 是静态站点，不能直接运行课程所固定的完整 Mathlib 环境。页面中的进度复选框会保存在当前手机浏览器的 `localStorage`。正式学习成果仍以 Git 仓库中的 Lean 文件和提交历史为准。
