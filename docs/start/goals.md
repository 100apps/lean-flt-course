# 课程目标

“弄懂整个仓库”不是一个开关，而是四级台阶。

## 第一级：读懂表面语法

看到下面的代码时，能够准确说出每个部分的意思：

```lean
theorem example (n : Nat) (hn : 3 ≤ n) : 0 < n := by
  omega
```

你需要认识类型、变量、假设、结论以及证明块。

## 第二级：读懂证明结构

能够解释一个大定理如何通过多个小定理组合起来，例如：

```lean
theorem contradiction (P : Prop) (hP : P) (hnP : ¬ P) : False :=
  hnP hP
```

这一级并不要求理解 `P` 背后的高级数学。

## 第三级：理解数学对象

理解为什么从费马方程反例要构造 Frey 曲线，以及“不可约”“模性”“降层”分别表达什么数学事实。

## 第四级：审核底层证明

能够进入代数几何、Galois 表示、模形式、变形理论与 Taylor–Wiles patching 的具体实现。这个层次是长期目标。

## 我们的学习契约

- 每次只引入少量新符号。
- 每一个抽象概念都先做玩具版本。
- `sorry` 只允许出现在练习副本里，不允许出现在答案和正式课程代码里。
- 每一课都保留可编译源码和 Git 提交。
- 不以“构建了整个仓库”冒充“理解了整个证明”。
