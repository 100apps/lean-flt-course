# 常见错误

## `type mismatch`

你提供的表达式类型与当前目标不同。先分别写下：

```text
Lean 需要什么类型？
我提供的东西是什么类型？
```

不要立即堆更多 tactic。

## `unsolved goals`

证明块结束了，但还有目标没有完成。查看 Goal 窗口或错误消息中剩余的目标。

## `unknown identifier`

Lean 找不到名字。检查：

- 拼写和大小写；
- 是否导入定义所在模块；
- 是否需要命名空间前缀；
- 名字是否只存在于目标 FLT 仓库而不在课程项目。

## `failed to synthesize`

Lean 找不到所需的类型类实例。初学时通常是对象类型不够明确，或缺少合适的 import。

## `declaration uses 'sorry'`

文件能够继续检查，但证明中仍有占位符。练习过程中允许；正式答案不允许。

## tactic 没有效果

- `rw` 需要目标中出现能匹配的等式一侧；
- `ring` 适合多项式恒等式；
- `omega` 适合自然数/整数线性算术，不处理变量相乘；
- `omega` 也未必会主动使用藏在结构体字段中的事实，可以先 `have h := P.hp5` 或显式把字段传给定理；
- `exact` 要求类型匹配；
- `apply` 适合结论与当前目标匹配的定理。
