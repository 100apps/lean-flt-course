# Lean 符号表

| Lean | 含义 | 常见输入 |
|---|---|---|
| `Nat` / `ℕ` | 自然数 | `Nat` / `\\N` |
| `Int` / `ℤ` | 整数 | `Int` / `\\Z` |
| `Prop` | 命题的类型 | `Prop` |
| `:` | “具有类型”或“目标是” | `:` |
| `:=` | 定义为/证明为 | `:=` |
| `→` | 蕴含或函数 | `->` |
| `∀` | 对所有 | `\\forall` |
| `∧` | 并且 | `/\\` |
| `∨` | 或者 | `\\/` |
| `¬` | 否定 | `\\not` |
| `≠` | 不等于 | `!=` |
| `≤` | 小于等于 | `<=` |
| `≥` | 大于等于 | `>=` |
| `⟨a, b⟩` | 构造一对证据 | `\\< a, b \\>` |
| `fun x => ...` | 匿名函数 | `fun` |
| `by` | 开始 tactic 证明 | `by` |

符号不是数学装饰。每个符号都会改变表达式的类型。
