# 词汇表

## elaborator（精化器）

把用户省略了许多信息的 Lean 源码补全为内核能检查的表达式。

## kernel（内核）

Lean 最小的可信检查核心。它检查最终证明项是否具有声明的类型。

## tactic

帮助逐步构造证明项的程序。tactic 本身不需要被盲目信任，因为生成的证明项仍由内核检查。

## theorem / lemma

二者在逻辑地位上没有本质区别，主要是命名和使用习惯不同。

## Mathlib

Lean 社区维护的大型数学库。目标 FLT 仓库建立在 Mathlib 之上。

## Frey package

仓库把规范化费马反例、素数指数及相关条件放在同一个结构体中，并据此定义 Frey 曲线。

## Galois representation

把域的对称性转化成线性变换的一种结构。FLT 中重点研究 Frey 曲线的模 `p` 扭点所产生的二维表示。

## irreducible（不可约）

粗略地说，该表示没有非平凡的不变子空间。正式定义要到后续课程学习。

## modularity（模性）

在本仓库中，表示椭圆曲线在好素数处的数据与某个权 2 规范化特征形式的数据匹配。它比一句口号有更精确的 Lean 类型。

## level lowering（降层）

在满足条件时，把模 `p` 表示对应的模形式换到更低 level。Frey 情况最终降到 level 2。
